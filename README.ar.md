# DMFlow — دليل التشغيل بالعربية

تطبيق فعلي مبني بـNext.js وTypeScript وPostgreSQL وPrisma، مع عامل مستقل لمعالجة الأحداث والرسائل. الواجهة عربية/إنجليزية وتدعم RTL والوضع الداكن والآيفون.

## الموجود في هذه النسخة

تسجيل حساب ودخول، ربط Instagram رسمي، اختيار المنشورات، حملات حسب الكلمات، رسالة خاصة ورد عام، منع التكرار، محرّر تدفقات مرئي، صندوق وارد، عملاء ووسوم، قاعدة معرفة، ردود AI قابلة للمراجعة أو الإرسال التلقائي، إحصاءات، نسخ A/B، روابط متتبعة، مواعيد وساعات عمل، سجلات، وإشعارات داخل الموقع.

هذه نسخة تطوير قابلة للتشغيل. لم يُربط بها حساب Meta حقيقي ولم تُنشر على استضافة عامة بعد. اختبارات الرسائل تستخدم محاكاة لاتصالات Meta ولا ترسل إلى أي حساب.

## تشغيل محلي

1. ثبّت Node.js 22 أو أحدث وPostgreSQL 16 أو أحدث.
2. نفّذ `npm ci` وانسخ `.env.example` إلى `.env`.
3. أدخل اتصال قاعدة البيانات في `DATABASE_URL` وحدد `APP_URL=http://localhost:3000`.
4. أنشئ مفتاح تشفير باستخدام الأمر أدناه وضعه في `TOKEN_ENCRYPTION_KEY`:

```sh
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
npm run db:generate
npm run db:migrate
npm run dev
```

شغّل العامل في نافذة ثانية:

```sh
node --env-file=.env --import tsx workers/index.ts
```

سجّل الحساب الأول. للاستخدام الشخصي أغلق التسجيل بعد ذلك بضبط `REGISTRATION_ENABLED=false`.

## تفعيل Instagram

أدخل مفاتيح تطبيق Meta على الخادم فقط. عناوين الإعداد على دومينك:

- OAuth: `/api/meta/callback`
- Webhooks: `/api/webhooks/instagram`
- حذف البيانات: `/api/meta/deletion`
- الخصوصية: `/privacy`

الصلاحيات المطلوبة وطريقة App Review وتفعيل الحساب موثقة بالتفصيل في `docs/meta-setup.md`. الموافقة من Meta لا يمنحها الكود. لا تضع أي سر في كود الواجهة أو في مستودع GitHub.

بعد الربط: اختر منشورًا، أضف الكلمات ونص الرسالة، احفظ التدفق ثم فعّله. قالب الرابط يحتاج رابط HTTPS حقيقيًا في خطوة Link قبل الحفظ. المتابعة تتوقف حتى يرد العميل. الرسائل غير المؤكد وصولها لا يعاد إرسالها تلقائيًا.

## النشر

يمكن نشر Next.js على Vercel، وتشغيل العامل على خدمة حاويات مستقلة وقاعدة PostgreSQL مشتركة. توجد أيضًا ملفات Docker وCompose ونسخ احتياطي يومي. تفاصيل الدومين وSSL والنسخ والاستعادة في `docs/deployment.md`.

المفاتيح اللازمة للتشغيل الحقيقي: Meta، ومزود AI عند تفعيله، واتصال قاعدة الإنتاج. مستودع المشروع: https://github.com/sisi79163-crypto/DMFlow

## الحدود الموثقة

الفريق والصلاحيات التفصيلية وWeb Push لم تُفعّل. الوارد يجمع الرسائل من وقت الربط؛ لا يستورد التاريخ السابق. الرسائل نصية، ومرفقات الوسائط غير معالجة. استعادة كلمة المرور بالبريد والتحقق من البريد يحتاجان خدمة بريد ولم يُنفذا هنا.

دليل الاختبارات والنتائج في `docs/verification.md`. جميع بيانات صور المعاينة تجريبية.
